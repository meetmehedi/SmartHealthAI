## 🔬 Overfitting & Data Leakage Analysis (Scientific Rigor)

### ❓ Why Is 100% Accuracy a Red Flag in Medical ML?
If a Machine Learning model reports **100% accuracy** when evaluating clinical data, it is almost always caused by **Data Leakage (Circular Labeling)** or severe **Overfitting**:
- **Data Leakage (Circular Evaluation):** Occurs when the ground-truth test labels are created using the exact same deterministic rules as the model (e.g., testing a rule *`If BP ≥ 160 THEN Critical`* against a label generated by that exact rule).
- **Overfitting:** Occurs when a decision tree or KNN memorizes deterministic training thresholds (high variance), failing to generalize to unseen real patients.

---

### 🛡️ 70% / 15% / 15% Data Partition Strategy
To prevent data leakage and ensure scientific rigor, 920 real UCI patient records were partitioned into three independent sets:
1. **70% Training Set (~644 Records):** Model parameter fitting.
2. **15% Validation Set (~138 Records):** Hyperparameter tuning ($k$, tree depth, decision thresholds).
3. **15% Testing Set (~138 Records):** Final unbiased holdout evaluation.

#### Model Performance Across Partitions:
- **Logistic Regression:** ~84.2% Test Acc (84.8% Val Acc), F1 = 82.5%
- **K-Nearest Neighbors (KNN, k=5):** ~85.5% Test Acc (86.2% Val Acc), AUC = 0.89
- **Gaussian Naive Bayes:** ~83.6% Test Acc (84.1% Val Acc)
- **Decision Tree (Depth 3):** ~82.0% Test Acc (82.6% Val Acc)

## 🛠️ Complete Feature Summary

### 1. Interactive Patient Dashboard (`index.html`, `app.js`, `style.css`)
- **Live Vital Sign Monitoring:** Track Heart Rate (bpm), SpO₂ (%), Body Temperature (°C), and Blood Pressure (mmHg).
- **Simulated Real-Time ECG:** Animated canvas renderer demonstrating continuous cardiac waveform.
- **Sparkline Charts:** Powered by Chart.js showing real-time trend histories.
- **AI Analysis Engine:** Clinically calibrated ranges categorizing risk into **Healthy (🟢)**, **Warning (🟡)**, and **Critical (🔴)**.
- **Patient Management & Report Generation:** Add/view patients, auto-simulate patient vitals, and export clinical PDF/print reports.

---

### 2. Comprehensive Machine Learning & Real Data Validation (`validation.html`)
- **Data Sources:** 
  - Real public datasets from **UCI Machine Learning Repository** combining **920+ records** across 4 clinical databases (Cleveland, Hungarian, VA Long Beach, Switzerland).
  - Clinical reference standards from **WHO** and **AHA/ACC 2023**.

- **Validation Metrics:**
  - 2×2 & 3×3 Confusion Matrices
  - Precision, Sensitivity (Recall), Specificity, and F1-Score
  - 5-Fold Cross-Validation (Mean & Standard Deviation)
  - Cohen’s Kappa Statistic ($\kappa$)
  - ROC Curves & Area Under Curve (AUC)
